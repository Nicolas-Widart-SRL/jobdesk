# Search Queries for Job Scraper

## Query Categories

### Priority 1: Platform and backend leadership

```
site:jobs.example.com "Lead Backend Engineer" Namur
site:jobs.example.com "Platform Lead" Brussels
```

### Priority 2: Logistics software

```
site:jobs.example.com route planning Rust Belgium
```

## Location Filter

- Namur, Charleroi and the surrounding area
- Brussels and Liege, hybrid
- Ghent and Antwerp (borderline, mostly remote only)

## Language Filter

Work in French or English. Dutch is fine for meetings, so flag postings that need it in writing.

## Date Filter

Only include jobs posted within the last 14 days, or with an application deadline that has not yet passed.
