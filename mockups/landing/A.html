Your files, laid out on one desk.

Jobs, Applications and Insights update live as commands change your files. These are the app's own screens, on fictional data.

Nothing runs until you start it.

Every task starts in the launcher.
Card actions only open it. You see the command line Claude will run, then press Run.
One run at a time.
Two commands could overwrite each other's files, so a second one waits.
Your own Claude Code signs in.
Jobdesk keeps no password. An optional API key stays in the system keychain.
You choose how much it asks.
Tool permissions are allowed by default and listed in the activity. Settings › Permissions turns prompts on.

Put your job search on a desk.

You need the Claude Code CLI, installed and signed in, and an ai‑job‑search checkout. On first launch, choose that folder.

macOS

For Apple silicon. Open Jobdesk-vX.Y.Z-macos-arm64.dmg and drag Jobdesk to Applications. Signed with a Developer ID and notarized by Apple.

Download for macOS

Windows

Run Jobdesk-vX.Y.Z-windows-x64-setup.exe. The installer is not signed yet, so SmartScreen warns: click More info, then Run anyway.
