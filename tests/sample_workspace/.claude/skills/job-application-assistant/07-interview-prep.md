# Interview Preparation Guide

## Ready-Made STAR Examples

### 1. Event-driven planning (Technical leadership)
**S:** Calder Freight planned 40 depots in one nightly batch, so a late truck broke the next day's plan.
**T:** Make plans update during the day without stopping the depots.
**A:** Moved planning to event streams in four steps, each behind a switch.
**R:** [OUTCOME]
**Use for:** "Tell me about a technical change you led"

### 2. Clinic booking outage (Calm under pressure)
**S:** The appointment service at Wren Health went down on a Monday morning.
**T:** Bring bookings back before the clinics opened.
**A:** Rolled back the release, then wrote the review the same day.
**R:** [OUTCOME]
**Use for:** "Tell me about a time something failed"

### 3. First import tool (Learning fast)
**S:** Pemberton Labs needed lab samples imported from five old formats.
**T:** Ship an import tool in my first month.
**A:** [WHAT YOU DID]
**R:** Every lab moved over within a quarter.
**Use for:** "Tell me about learning something new quickly"
